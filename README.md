# Portfólio · Joalyson

Landing page do portfólio de Joalyson, motion designer e designer gráfico. Reúne trabalhos reais de campanhas, eventos e marcas, com vídeos, e os contatos para orçamento.

## Stack
HTML, CSS e JavaScript, sem build nem dependências. Fontes do Google Fonts.

## Estrutura
- `opcao-4-caderno/index.html` — a página
- `assets/works/` — vídeos e capas dos trabalhos
- `assets/photos/` — fotos do Joalyson
